## Where things live
- `tools/*.ps1`: build, launch/stop-editor, run-tests, unreal-python, blender-run, cleanup, codemap; status in `Saved/AgentLogs/status/`.
- `Saved/AgentLogs/`: `tests/`, `qa/`, `playtest/`, `editor/`, `build/`, `design/`, `levels/`, `anim/`, `model/`, `previews/`, `scratch/`, `status/`.
- Lanes: C++ worktrees `C:\GameDev\VibeGame-lanes\<lane>` on branch `lane/<lane>` (eng1..eng6, qa1); the main checkout is the editor lane.
- Data sources: `data/tables/DT_*.csv|json` (truth; binary `/Game/Data/DT_*` is imported), level layouts `data/levels/*.json`.
- Design truth: `docs/GAME_DESIGN.md`, `docs/ART_STYLE.md`, `docs/TASKS.md` (who is on what), `docs/TEST_PLAN.md`.

## Ignore
- `Source/VibeGame/Variant_*` are unused UE template leftovers; no Lure code uses them (`.rgignore` hides them).
- The root `VibeGameCharacter/GameMode/PlayerController` are template classes too; Lure uses the `Lure*` classes.
