Found 2026-09-22 by qa-engineer, report `Saved/AgentLogs/tests/20260922-221822/`. Owner: unreal-engineer (`Playtest/PlaytestNoteWriter.cpp`). All four FIXED 2026-09-22 in 1e4825b by unreal-engineer; `-Filter Project` 51/51 pass, report `Saved/AgentLogs/tests/20260922-222806/`.
- FIXED in 1e4825b: T003-B1 `Json.NonFiniteNumbersStayValid`: a NaN/Inf location, game time or FPS is written as `nan`/`inf`, so note.json is invalid JSON (Python `json`, PowerShell `ConvertFrom-Json` and jq reject it; the engine reader accepts it). Fix: NaN/Inf are written as `null`, and WriteNote reports the affected fields as one warning.
- FIXED in 1e4825b: T003-B2 `Failure.PixelCountMismatch`: the note folder is created before the pixels are validated, so a rejected write leaves an empty note folder. SubmitNote then drops the typed note. Fix: inputs are validated before anything is created. A bad or unwritable screenshot is dropped (`"screenshot": ""`, warning) and the note is still saved. Only a failed note.json returns false, and then the folders the call created are removed. On failure SubmitNote logs the text and the full note.json at Warning level.
- FIXED in 1e4825b: T003-B3 `Failure.EmptyRoot`: an empty root resolves against the process dir, and the note was written into `Engine/Binaries/Win64`. Fix: an empty or whitespace-only root is rejected with an error, and nothing is written.
- FIXED in 1e4825b: T003-B4 `Git.MalformedRepoIsUnknown`: non-hash HEAD/ref content (`this is not a commit`, `not-a-hash`, `abc123`) is returned as the commit id instead of "unknown". Fix: only 40 or 64 hex characters (trimmed) are accepted, otherwise "unknown". HEAD refs must be under `refs/`. A broken loose ref no longer falls back to a stale packed id.
